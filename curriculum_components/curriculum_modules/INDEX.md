# curriculum_modules/ — INDEX

The 13 human-authored **master modules** (`Area N Task X PPL.md`) — the canonical teaching source,
authored as Google Docs in Drive (`AVIAIONCHAT/ACS Modules`) and exported here as `.md`. Each master
names its FAA sources in a Bridge Keys block, then gets split into micro-lessons
(`pipeline/curriculum/elements/`) and drives the RKP manifest + quiz bank for its lessons.

**Never overwrite a master outside an explicit Drive-pull session** (constitution.project.md) —
Drive is the authoring surface; these files are machine truth.
