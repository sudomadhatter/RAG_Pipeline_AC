# Lesson 19: Class A, B, and C Airspace
## PPL_PA_I_E_01 | ACS Elements: PA.I.E.K1a, PA.I.E.K1b, PA.I.E.K1c

### What This Lesson Covers
The three busiest airspace classes in the National Airspace System: Class A (IFR only, no exceptions), Class B (explicit clearance, wedding-cake shelves), and Class C (radio contact only, not clearance). Plus the Mode C Veil and ADS-B Veil that extend 30 NM beyond Class B boundaries.

### The Four Knowledge Points

**RKP_01: Class A — FL180 and Above, IFR Only**
FL180 (18,000 MSL) to FL600. No VFR. No Special VFR. No exceptions.
Requirements: IFR clearance, two-way radio, discrete transponder, ADS-B Out.
Altimeter: 29.92 in Hg set (standard pressure) above 18,000 MSL (14 CFR 91.121).
DPE trap: 'Can you fly VFR at FL180?' — No. That IS Class A.

**RKP_02: Class B — The Wedding Cake**
Tiered shelves; floor and ceiling vary by shelf. Read sectional (e.g., '60/SFC').
Requirements: (1) Explicit ATC clearance (must hear 'Bravo' or 'Class Bravo' verbally). (2) Mode C. (3) Two-way radio. (4) ADS-B Out.
Student pilot restriction: CFI must endorse the student specifically for the Class B airport (14 CFR 61.95).
VFR inside Class B: 3 SM visibility, clear of clouds (no cloud separation distances required inside B).

**RKP_03: Class C — Communication, Not Clearance**
5 NM inner circle: surface to 4,000 AGL. 10 NM outer circle: 1,200 to 4,000 AGL. 20 NM outer area: attempt contact.
Requirements: two-way radio established (ATC acknowledges callsign = in. 'Standby' = good enough). Mode C. ADS-B Out.
No explicit clearance needed. No student pilot restriction.
VFR minimums: 3 SM, 500 below/1,000 above/2,000 horizontal clouds.

**RKP_04: Mode C Veil and ADS-B Veil — The 30 NM Rules**
Mode C Veil (91.215): within 30 NM of ANY Class B primary airport, surface to 10,000 MSL. Mode C transponder required — even outside the Class B shelves.
ADS-B Veil (91.225): same 30 NM footprint. ADS-B Out required.
DPE trap: 'You''re 28 NM from Atlanta, at 5,000 feet, under Class B airspace but outside the B shelves — what equipment?' Answer: Mode C AND ADS-B Out.

### Key Regulations
- 14 CFR 91.135 — Class A entry requirements
- 14 CFR 91.131 — Class B entry requirements
- 14 CFR 91.130 — Class C entry requirements
- 14 CFR 91.121 — Altimeter settings (29.92 above 18,000)
- 14 CFR 91.215 — Mode C transponder requirement (30 NM veil)
- 14 CFR 91.225 — ADS-B Out requirement
- 14 CFR 61.95 — Student pilot Class B restriction
