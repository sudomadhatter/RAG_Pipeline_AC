# Lesson 21: VFR Weather Minimums and Special VFR
## PPL_PA_I_E_03 | ACS Element: PA.I.E.K2

### What This Lesson Covers
The complete 14 CFR 91.155 weather minimums table — all six sets — with no shortcuts, Special VFR clearances and their night restriction, the controlled vs. uncontrolled airport trap for untowered Class E airports, and the RVR vs. SM unit confusion that puts pilots in IMC.

### The Four Knowledge Points

**RKP_01: The Full 91.155 Table — Six Minimum Sets**
| Airspace | Visibility | Cloud Separation |
|---|---|---|
| Class B (inside) | 3 SM | Clear of clouds |
| Class C, D, E below 10,000 MSL | 3 SM | 500 below / 1,000 above / 2,000 horiz |
| Class E at/above 10,000 MSL | 5 SM | 1,000 below / 1,000 above / 1 SM horiz |
| Class G day ≤1,200 AGL | 1 SM | Clear of clouds |
| Class G day >1,200 AGL <10,000 MSL | 1 SM | 500 below / 1,000 above / 2,000 horiz |
| Class G night ≤1,200 AGL | 3 SM | Clear of clouds |
| Class G night >1,200 AGL | 3 SM | 500 below / 1,000 above / 2,000 horiz |

Class B clear-of-clouds: because ATC separates all IFR traffic inside Class B — you don't need the cloud buffer.
Above 10,000: more visibility because faster aircraft, higher closure rates.

**RKP_02: Special VFR — Pilot Requests Only, Night Restriction**
14 CFR 91.157: VFR in surface areas below standard VFR minimums.
Requirements: pilot requests it (ATC cannot offer), 1 SM and clear of clouds minimum maintained.
Only valid inside surface area lateral boundaries (Class B/C/D/E surface).
Night SVFR: pilot must be instrument rated AND aircraft must be IFR equipped. Night SVFR without instrument rating = illegal.
Some Class B airports prohibit SVFR — check Chart Supplement special notices.

**RKP_03: The Untowered Class E Trap**
Untowered ≠ uncontrolled. A dashed magenta boundary = Class E from surface = 3 SM and 500/1,000/2,000 required.
No dashed magenta = Class G surface = daytime 1 SM clear of clouds.
Flying into an untowered Class E field in 2 SM/800-foot ceiling = BELOW MINIMUMS, even though no one is talking to you.

**RKP_04: RVR vs. Statute Miles — Don't Confuse Them**
METAR prevailing visibility in SM: '5SM' = 5 statute miles. Standard.
METAR RVR: 'R18/4000FT' = 4,000 FEET on Runway 18 ≈ 0.75 statute miles.
VFR minimums are in STATUTE MILES. RVR 4000 ≈ 0.75 SM — below VFR minimums.
Never use RVR as your VFR go/no-go decision number. Use prevailing visibility in SM.
